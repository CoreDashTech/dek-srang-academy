# DEK SRANG Academy — Football Development Platform
โดย CoreDash Technology · PWA ไทย/English · ใช้ออฟไลน์ได้ · ติดตั้งเป็นแอปได้

## เมนู
ภาพรวม · นักเตะ (โปรไฟล์ การ์ด ส่วนสูง-น้ำหนักเทียบเกณฑ์อ้างอิง ทักษะเรดาร์ สมรรถภาพ แมตช์ สุขภาพ/พักผ่อน แผนพัฒนา) · ฝึกซ้อม & เช็กชื่อ · แมตช์ & สถิติ · ห้องวิเคราะห์กราฟ (เลือกแกน X/Y, เส้นแนวโน้ม, ค่า r) · แนวทางพัฒนา (ทักษะ ร่างกาย อาหาร นอน กีฬาเสริม) · ทีมและโค้ช · รายงานผู้ปกครอง (พิมพ์/PDF) + Excel · ตั้งค่า

## ขึ้น GitHub Pages
1. สร้าง repo ชื่อ `dek-srang-academy` (Public) อัปโหลด **เนื้อหาในโฟลเดอร์นี้** ไว้ที่ราก repo (index.html อยู่ชั้นนอกสุด)
2. Settings → Pages → Deploy from a branch → `main` / root
3. เปิด `https://<org>.github.io/dek-srang-academy/`  · อัปเดตแล้วกด Ctrl+Shift+R

## หมายเหตุ
- มีข้อมูลตัวอย่าง 24 คน 3 ทีม → ตั้งค่า → ข้อมูล → "ล้างข้อมูลทั้งหมด" เมื่อใช้งานจริง
- ค่าส่วนสูง/น้ำหนักอ้างอิงเป็นค่ากลางโดยประมาณ ใช้ดูแนวโน้มเท่านั้น ไม่ใช่การวินิจฉัย
- เนื้อหาแนวทางพัฒนาเป็นข้อมูลทั่วไปเพื่อการศึกษา ไม่ใช่คำแนะนำทางการแพทย์
- บทบาท (ผู้ดูแล/โค้ช/ผู้ปกครอง) เป็นการจำลองในเครื่อง ระบบล็อกอินจริงเป็นเฟสถัดไป
- ข้อมูลเด็กเป็นข้อมูลส่วนบุคคล มีช่องหนังสือยินยอมผู้ปกครอง
